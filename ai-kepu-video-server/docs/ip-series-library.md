# InsightCut · 长期讲故事的 IP 角色库

## 和单次分镜有何不同？

IP 角色库在「项目」之上。角色名字、性格、固定外貌和服饰、叙述口吻、常用世界观、禁止变化项、参考形象图片以及可选的 TTS 声音 ID 都可被多个视频共享。

例如创建一次「阿财熊猫」，第 1 集讲复利、第 2 集讲消费、第 3 集讲储蓄，所有项目都使用同一份 IP 形象设定。

每个项目保存的是选定 **版本快照**：
- 日后在角色库修改设定不会悄悄修改旧项目。
- 新项目选择该 IP 时使用最新版本。
- 参考图上传后做内容验证并保存在 `data/media/_ip_library/references/`。
- IP 角色库元数据保存在 `data/media/_ip_library/profiles.json`。
- 每个视频的绑定快照保存在 `data/media/_ip_library/projects/{task_id}.json`。
- 项目与 IP 绑定发生在脚本和分镜工作启动之前。

## 从页面使用

1. 启动 InsightCut 前后端，进入 **文稿编辑 / 创建视频**。
2. 在「生产预设」选择「固定讲述者 IP」→「新建 IP」。
3. 填写人物人设、固定外观和服装、讲述风格、世界观、镜头风格、禁止事项。上传 320×320 或更清晰的固定角色参考图片（JPG/PNG/WEBP，最多 20MB）。
4. 可选：设置与已接入 TTS 服务相符的音色 ID，如 `mimo:冰糖`。这只选择音色；实际 TTS 仍需对应 Provider 的有效密钥。
5. 保存后自动选中 IP，输入本期文稿，点击「生成预案」。
6. 全片分镜导演会读取 **固定 IP + 当前故事**，将人设锁定写入提示词、推荐镜头动作。
7. 配置百炼万相生图后，每个镜头将参考固定的角色图，生成不同场景中的同一个角色。
8. 需要动态画面时，在镜头编辑器单独触发万相图生视频；导出 MP4 时仍以现有素材、音轨和字幕为准。

## 技术边界

- 角色图参考是**提高一致性的条件约束**，不是像素级身份保证；模型仍可能出现脸、服饰和四肢细节漂移，需人工审片、单镜头重做。
- 初版一个 IP 保存一张固定形象参考图。多视角/表情/动作 LoRA 或统一 3D 模型暂未实现。
- 初版长视频采用全片视觉设定 + 分段生成提示词；还没有跨镜头的多模态画面一致性评分器。
- TTS 音色选择可保存并跨项目复用，但没有新增语音服务。当前已接入的声音 Provider 仍需开通。
- 生图/生视频费用按照各服务商账号实际用量结算，创建 IP、修改设定和创建分镜不会自动生成付费视频。
- 参考图需为用户有权使用的原创或授权内容。
- 没有选择 IP 的项目继续按旧版流程生成；不会强制全局设置角色。

## 可执行的本地检查

在 `ai-kepu-video-server` 目录：

```bash
python -m pytest -q tests/test_ip_library.py tests/test_wan_image_storyboard.py tests/test_wan_i2v.py
python -m compileall src api_server.py
```

在 `ai-kepu-video-web/frontend` 目录：

```bash
npm run lint
npm run build
```

真实模型调用和完整 MP4 生成需要本机具备有效 API Key、TTS Provider 与 FFmpeg，并且应先使用只有 2～3 个分镜的短项目控制成本。
