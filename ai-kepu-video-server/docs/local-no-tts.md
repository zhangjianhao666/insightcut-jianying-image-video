# InsightCut：无旁白视频闭环（无需 TTS 账号）

本模式专门用于第一阶段的「文案 → AI 分镜 → 百炼生图 →（按需）万相图生视频 → FFmpeg MP4」流程。**并没有使用文字转语音模型**。

## 操作步骤

1. 启动 `codex/wan-i2v-shot-closure` 分支。
2. 进入 **API 配置 → 生文模型**，选择「自定义兼容接口」，填写你已验证成功的百炼工作空间 URL、Qwen 模型和 Key。
3. **图片生成**选择「百炼万相」，使用同一工作空间的 `/api/v1` 地址及有生图权限的 Key。
4. **配音模型**勾选「暂不配置配音服务，允许保存 LLM / 生图设置」，然后点击「保存配置」。这不会帮你配置豆包或 MiMo，也不会保证其真实语音可用。
5. 创建视频，在 **生产预设 → 配音方式** 选择「无旁白（本地静音，先完成画面闭环）」。
6. 输入主题，选择视觉风格和 IP，生成分镜预案。
7. 工作台音频模式会默认选中「无旁白（仅画面）」；点击「确认无旁白模式」，再确认生产。
8. 后端为每段旁白文案自动写出合法 WAV 静音音轨（24kHz、单声道、16位，每段时长估计 3–15 秒），与实际图片一起存档并进行 MP4 生成。
9. 如需真实动态镜头，在分镜面板单独调用万相图生视频，再重新导出 MP4。

## 设计原因

InsightCut 现有任务、素材版本、预览和导出器都将音频当作时长锚点。完全删除音频会影响大量数据库、预览和剪映导出逻辑，所以本阶段采用**本机静音占位轨**实现可靠闭环，不调用任何 TTS API。视频最终可能包含静音音轨，但没有旁白。

## 注意事项

- 「无旁白」只是跳过 **TTS 调用**，生文、生图和图生视频仍按百炼账号实际计费。
- 每段静音的时长只是根据字数估算；并非根据真实语音对齐。以后启用 TTS 时应重新生成语音和字幕时间轴。
- 即便勾选了无旁白模式，选择真实豆包/MiMo 声音的项目仍须通过相关 TTS API 权限校验。
- 这项改动未验证真实百炼生图 / 视频服务的全部组合，也未通过完整 Mac GUI 端到端检查。
- 原项目可创建不使用任何 IP 的视频；IP 和无旁白可以独立使用。

## 离线测试

从 `ai-kepu-video-server/` 运行：

```bash
python -m pytest -q tests/test_silent_video_mode.py
```

从 `ai-kepu-video-web/frontend/` 运行：

```bash
node --test tests/silentVideoMode.test.mjs
```

完整前端回归（建议）：

```bash
npm run lint
npm run build
```
