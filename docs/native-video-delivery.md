# H3 原生科普视频闭环修复设计

目标：指定 IP 和画风后，两个独立 H3 分镜自动形成带原生对白、同步中文字幕、总长不超过 10 秒的 MP4。保留旧图片/TTS/草稿流程。此次先验证短片闭环，不宣称已验证长视频稳定性。

## 方案选择

采用原生音轨 + 本地语音识别验收 + 自动交付处理。仅靠 prompt 和固定时间字幕不能可靠处理迟起对白；整片 TTS 可以控制音色但会替换用户要测试的 H3 原生对白，因此不采用。声音参考继续固定在 IP 快照，两镜头共用同一版本。

## 导演规划

先复现实际配置下失败的具体阶段，不假设服务商或模型名称错误。异常持久化阶段、脱敏错误类型及项目 ID，禁止输出凭证或原始模型响应。短片计划必须覆盖每个分镜并满足结构/动作描述要求；失败和空计划不缓存为有效成功。不允许付费批量生产静默使用通用动作兜底；保留现有文本图片资产并明确提示重新规划。修复根因后用当前两句脚本验证详细动作、角色服装和画风约束。

## 原生音轨交付

在现有逐镜头生成完成之后加入独立、可恢复的本地交付阶段。保留原始分镜和未处理拼接输出。使用可配置的本地 Whisper 识别后端，模型路径明确配置；不在后台隐式下载模型、不增加云 ASR 费用。不可用时报告交付阻塞，保留原生文件，不能假称字幕成功。

按每镜头真实语音时间验收台词，保守处理中文标点和同音识别误差；不将 ASR 字面差异直接判定为视频说错。严重缺句/多句提示人工复核，不能仅靠脚本文本伪造验收。时间轴覆盖完整语音，使用 SubtitleWriter 输出真实 SRT/VTT，字幕为项目原文。通过 FFmpeg 烧录中文字幕，预检所用二进制的字幕滤镜能力，失败保留中间资产。

总长目标作为明确参数快照传入后处理和状态。此次 10 秒；先移除语音之外可安全裁剪的首尾空白，保留短前后缓冲。不截断对白、不静默加速声音。若有效语音与必要缓冲仍超时，交付阻塞并提示缩短文稿；不自动重新提交付费任务。最终探测时长、音视频流和文件存在性，再标记完成。字幕与交付文件正确登记资产，失败保留已有结果。

## 状态与恢复

原生视频流程使用自己的生成、转写、字幕、渲染、完成或交付阻塞状态。工作台主状态读取这个流程时不再要求旧 TTS 素材齐全。旧任务状态和资产不伪造为配音成功。持久化交付参数、源文件身份、输出信息；本地处理重试复用已付费视频，不重复调用 H3。输入或声音版本改变时已有输出判为过期。

## 验证

回归覆盖空计划失效、完整镜头覆盖、脱敏错误、对白晚起、混合静音、超过预算且不能裁剪、缺失识别模型/字幕滤镜、失败保资产、本地重试不提交 H3、原生主状态不依赖 TTS。用现有真实两镜头从原始文件重新跑自动交付，验证恰好两个分镜、总长 <=10 秒、H264/AAC、中文字幕和可下载播放。后端 ruff、相关测试；前端 lint 与状态组件测试；贡献检查。新的付费生成只在确有必要且原授权范围允许时执行，不静默扩大镜头数。

## 导演到分镜图

H3 的 review_first 新项目由既有导演先按完整文稿确定语义分镜和逐镜时长，再生成构图、动作及首帧提示词；旧 full/TTS 分段流程保留。generation_options.target_duration_seconds 可固定总时长，单次仍为1–12镜、每镜4–15秒、最多180秒。分镜文本拼接必须完整保留原文，总时长必须匹配；模型未通过结构校验不得以通用描述宣称成功。导演边界方案先保存检查点，重试和重新规划保留时长。

MiniMax 图片服务使用 image.provider=minimax、官方 /v1/image_generation、image-01。每镜 n=1，关闭提示词优化，传入导演描述、统一画风与本地 IP 参考图，Base64 输出校验真实图片及尺寸后存档。参考图、DataURL 和凭证不进入日志。IP外观/服装字段必须与参考图一致；仅绑定图片不保证人物不变。生图失败与人工发现的身份漂移均应保留历史素材，不能宣称视觉验收通过。
